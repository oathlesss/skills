# Mod Idea Bank

When the user wants to start a new learning mod or needs inspiration, point them to the
idea bank in Obsidian:

**`/home/ruben/obsidian-vault/inbox/minecraft-mod-ideas-learning.md`**

Contains 625 original, small-scoped mod ideas (208KB) organized by category:

| Category | Count | Focus |
|----------|-------|-------|
| 🟢 Beginner | 103 | Blocks/items only — no entities, GUIs, or networking |
| 🟡 Intermediate | 104 | Entities, worldgen, data components |
| 🟠 Advanced | 103 | GUIs, networking, BERs, HUDs, Mixins, custom sounds |
| 🔧 Tech | 105 | Redstone gadgets, single-block machines, automation-lite |
| ✨ Magic | 105 | Spells, rituals, enchantments, mystical items, alchemy |
| 🗺️ Exploration | 105 | Structures, navigation, treasure, landmarks, discovery |

Each entry includes: one-line description, flavor sentence, NeoForge concepts taught,
and estimated file count. All scoped to 1–3 learning sessions.
