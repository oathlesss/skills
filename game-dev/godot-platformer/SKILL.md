# Godot 4 Platformer Physics

Proven patterns and gotchas for CharacterBody2D movement in Godot 4.

## Surface sticking (wall/ceiling walking)

The laziest way: set `floor_max_angle = PI` in `_ready()`. `move_and_slide()` treats every surface as floor. Walk on walls, ceilings — zero extra code.

```gdscript
func _ready():
    up_direction = Vector2.UP
    floor_max_angle = PI  # any surface is floor
```

## up_direction-relative vector math

Once `up_direction` can change (wall/ceiling sticking), ALL physics must be relative to `up_direction`. Never use `velocity.x`/`velocity.y` directly — use dot products and rotations.

| What | Formula | On flat ground (up=0,-1) |
|------|---------|--------------------------|
| **Gravity direction** | `up_direction.rotated(PI)` | `(0,1)` = DOWN ✓ |
| **Surface tangent (right)** | `up_direction.rotated(PI/2)` | `(1,0)` = RIGHT ✓ |
| **Surface tangent (left)** | `up_direction.rotated(-PI/2)` | `(-1,0)` = LEFT |
| **Jump direction** | `velocity += up_direction * impulse` | `vy -= 600` = UP ✓ |
| **Moving "upward"?** | `velocity.dot(up_direction) > 0` | vy < 0 → dot > 0 ✓ |

## Movement along surface

Decompose velocity along the surface tangent. Never overwrite `velocity.x`/`velocity.y` — it fights gravity on walls.

```gdscript
func _handle_movement(delta):
    var tangent := up_direction.rotated(PI / 2)  # always points "right" on surface
    var target_speed := input_dir * walk_speed
    var current_speed := velocity.dot(tangent)
    var new_speed := move_toward(current_speed, target_speed, accel * delta)
    velocity += tangent * (new_speed - current_speed)  # only along tangent
```

## Jump with coyote time + jump buffer

```gdscript
func _handle_jump():
    if Input.is_action_just_pressed("jump"):
        jump_buffer_timer = jump_buffer_time
    
    # Variable jump height — cut on release (only during ascent)
    if Input.is_action_just_released("jump") and velocity.dot(up_direction) > 0:
        velocity -= up_direction * velocity.dot(up_direction) * (1.0 - jump_cut_multiplier)
    
    if jump_buffer_timer > 0 and coyote_timer > 0:
        velocity += up_direction * jump_impulse  # NOT -=
        coyote_timer = 0
        jump_buffer_timer = 0

func _handle_timers(delta):
    if not is_on_floor():
        coyote_timer -= delta
    else:
        coyote_timer = coyote_time
    jump_buffer_timer -= delta
```

Pitfall: don't reset `coyote_timer` in both `_handle_jump` AND `_handle_timers`. Pick one place (timers).

## Gravity

```gdscript
func _apply_gravity(delta):
    if not is_on_floor():
        velocity += up_direction.rotated(PI) * gravity * delta
```

## Common sign-error gotchas

- `PI/2` = counter-clockwise (tangent points RIGHT on flat ground). `-PI/2` = clockwise → inverted controls.
- `velocity += up_direction * impulse` → UP. `-=` pushes into ground (invisible).
- `velocity.dot(up_direction) > 0` = moving "upward" relative to surface. `< 0` = falling.

## Testing in headless mode

Scripts need `extends SceneTree` with `_init()`:

```gdscript
extends SceneTree

func _init():
    await process_frame  # give engine a frame
    # ... run tests ...
    quit(0)
```

`class_name` declared classes are NOT resolved when running with `-s`. Use `load()` to get the script/scene instead:

```gdscript
var scene = load("res://scenes/player.tscn")
var player = scene.instantiate()
root.add_child(player)
# Access exported vars: player.get("walk_speed")
# Call methods: player.call("_apply_gravity", 0.016)
```

Run: `godot --headless --path . -s tests/test_player.gd`

Template: `templates/headless_test_runner.gd` — copy, add test functions, run.

## Scene file gotchas

- Don't use `uid://` references across scenes unless generated by the editor. Omit the uid line and use `path=` instead.
- Sub-resources (RectangleShape2D etc.) are per-file scoped. `floor_col` in arena.tscn is unrelated to `floor_col` in player.tscn — use unique names within each file.
- `load_steps=N` must match the actual number of `ext_resource` + `sub_resource` entries.

## Physics ticks

Set `physics/common/physics_ticks_per_second=120` in `project.godot` for responsive input at high framerates. Helps with `move_and_slide()` precision on walls.
