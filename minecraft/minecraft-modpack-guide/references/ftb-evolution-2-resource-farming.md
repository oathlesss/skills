# FTB Evolution 2 — Resource Farming Mods

Extracted Oct 2026 from the official mod list (feed-the-beast.com/modpacks/135-ftb-evolution-2/mods).
Pack facts: Minecraft 26.1.2, NeoForge, pack version 1.2.2, ~300 mods, released 2026-10-08, FTB ID 135.

## Resource farming mods, by category

### Crop / resource farming
- **Mystical Agriculture** (backbone — grow any resource as crops) + addons: Mystical Agradditions, Mystical Agriculture Tiered Crystals, Mystical Automation, Mystical Customization, Growth Accelerator Tiers.
- **Productive Bees** (passive resource bees) + **Mystian Apiary** (multiblock apiary expansion).
- **Nautec 2** — ocean tech; bacteria farming grows renewable resources.

### Farm automation
- **Agritech: Evolved (ATE)** — the pack's dedicated farming-automation mod (planters, machines, modules, power gen). Replaces Industrial Foregoing's plant sower/gatherer role.
- **Farming for Blockheads** — market, fertilizer, sprinklers (early food/crop QoL).
- **Productive Farming** — 160 crops with genetic traits + breedable flowers.
- **Horse Powered** — early-game animal-driven machines (grinding/chopping/crushing), also generates FE.

### Mob farming
- **Hostile Neural Networks** — passive mob loot via data models + simulation chambers (server-friendly).
- **Mob Flow Utilities** — mob-farm automation.
- **Apotheosis + Apothic Spawners** — spawner control (silk-touch spawners, upgrades).
- **Easy Villagers** / **Easy Piglins** — automated villager trading / piglin bartering.
- **Animal Pens** — lag-friendly passive animal farming.

### Passive / void resource generation
- **BBL Dimensional Resources** — "obtaining resources from other planets using an interdimensional laser" (void-mining style).
- **Occultism** — summon miner spirits (Djinn) to extract ores passively.
- **Stellaris** (+ **Mars**) — off-world factory: rocket → Moon → orbital station.

### Tech that drives farming (processing/mining)
- **Industrial Contraptions (by FTB)** — IC2-inspired tech core (ore processing, generators). NOT a farming mod despite the name.
- **Oritech**, **XyCraft: Machines**, **Energized Power**, **Just Dire Things** — machines + automation.
- **Mining Gadgets**, **FTB Ultimine**, **JustHammers** — accelerated manual mining.
- **GeOre** — reworks ore *generation* (makes mining more rewarding; not a farming mod).

## Notably ABSENT (players coming from ATM / old FTB will look for these)
No Mekanism, Industrial Foregoing, Immersive Engineering, Thermal, Create, Botania, RFTools, Actually Additions, Draconic Evolution, or Ex Nihilo/Ex Deorum.
The "passive resource" role is consolidated into Mystical Agriculture + Productive Bees + Nautec bacteria; farm automation lives in Agritech: Evolved.
