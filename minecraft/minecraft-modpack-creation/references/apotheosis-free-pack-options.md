# Apotheosis-free pack options (1.21.1 kitchen-sink)

Verified research (Modpack Index mod lists, Oct 2026). Question that triggered this:
"ATM10-like but without Apotheosis and the Apothic mods."

## What "the Apothic mods" means
On 1.21 Apotheosis split into modules, all by Shadows_of_Fire:
- Apotheosis (core)
- Apothic Attributes (required lib)
- Apothic Enchanting
- Apothic Spawners
- Apothic Attractions
- Placebo (required library, Shadows_of_Fire)

**Strip recipe** = delete all the above jars from `mods/`. Works cleanly in most packs EXCEPT
ATM10 itself, which weaves Apotheosis into its ATM-star progression + ATM-specific tweaks
(removal gets messy there). Better strip targets: FTB Evolution or Enigmatica 10.

## Nerf-instead-of-remove options
- **Apothic Nerf** (mod, 1.21.1 NeoForge, author "gts") — rebalances affixes/gems/spawners.
- **Apotheosis Nerf** (datapack, Modrinth).

## Takeaway
No ready-made ATM10-scale kitchen-sink pack excludes Apotheosis — it is now a default mod
(same tier as JEI). Realistic paths:
1. Strip the jars from FTB Evolution / Enigmatica 10.
2. Nerf via Apothic Nerf / Apotheosis Nerf datapack.
3. Build on Ruben's own Oathless Server Pack (161 mods) — add ATM-style content (Mekanism, AE2,
   Ars Nouveau, Create, etc.) and never include Apotheosis.
